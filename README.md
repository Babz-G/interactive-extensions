## 📌 Project Description & Purpose

An interactive browser extension manager built with React. Users can view a list of extensions, toggle them on or off, filter by active or inactive status, add new extensions, and remove existing ones. The app also includes a light/dark mode toggle.

## ✨ Features

- 🧩 Browse a list of browser extensions with names and descriptions
- 🔘 Toggle extensions on or off with a switch
- 🔍 Filter extensions by All, Active, or Inactive status
- ➕ Add a new extension via a modal form
- 🗑️ Remove extensions from the list
- 🌙 Light/dark mode toggle
